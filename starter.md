Intro to Repository Management
Learn the basics of several GitHub features that can help support a collaborative, friendly, and healthy project.

Who is this for: Developers with the need to start collaborating.
What you’ll learn: The different ways to protect your repository’s content as more people join as collaborators.
What you’ll build: You will prepare Mergington High School’s extracurricular activities website repository so additional teachers can safely collaborate.
Prerequisites:

Skills exercise: Introduction to GitHub
Skills exercise: Communicate using Markdown
Skills exercise: Review pull requests
How long: This exercise takes less than one hour to complete.
In this exercise, you will:

Add a simple rulesets and configuration to restrict repository content.
Communicate procedures to help guide collaborators.
Assign responsibility of parts of the code to particular collaborators.
Learn the difference between collaboration in a personal repository and organization repository.
Establish ground rules to promote a health collaboration environment.
Establish a process for managing security updates.
